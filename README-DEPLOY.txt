Dead Valley - Multi-device edition

Deploy to Vercel:
1. Extract this ZIP.
2. Import the project folder into Vercel (or upload the extracted folder using a supported deployment workflow).
3. Framework preset: Other. Build command: leave empty. Output directory: ./
4. Deploy. This is a static HTML/JS game and requires no server runtime.

Controls:
- Touch devices: on-screen directional controls and action buttons in landscape.
- Keyboard: arrows or WASD. Other actions keep the original default keys.
- Gamepad: standard Gamepad API; D-pad / left stick for movement, A for interact, X for inventory.
- Settings on the main menu: customize keyboard bindings and select Low / Medium / High display quality.
- Small bottom-left control toggles fullscreen.

Notes:
This project retains the original game logic and assets. The resolution presets tune visual presentation; the game engine's internal canvas remains at its original 900x600 logical resolution.

Ad-free build: advertising embed code and third-party Google Analytics tracking have been removed. The game does not intentionally load ad networks.
